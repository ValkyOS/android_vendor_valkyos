# ValkyOS boot animation

The packaged animation targets the Motorola Edge 50 Pro (`eqe`):

- canvas: 1220 x 2712;
- frame rate: 30 FPS;
- `part0`: 60 frames, played once;
- `part1`: 60 frames, repeated until Android finishes booting.

`bootanimation.zip` is intentionally stored without compression for Android's
boot animation loader.
